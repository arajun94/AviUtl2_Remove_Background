## AviUtl2 Remove Background
AIが動画の背景を取り除きます

<video src="demo.mp4" controls="true"></video>

GTX16以降を推奨

## インストール方法
1. python3.13と最新版のGeforceドライバをインストール
2. installer.exeを実行してインストール
3. AviUtl2を開き、上のバーから「表示」=>「AviUtl2 Remove Background」を選択
